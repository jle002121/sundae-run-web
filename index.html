Put it on your Home Screen

Open this page in Safari or Chrome, then use your browser’s “Add to Home Screen” option.

  1. In Safari, tap the Share button.
  2. Choose Add to Home Screen.
  3. Tap Add. Sundae Run will open like an app.

Backup & restore

Your entries—including saved photos—live in this browser. Export a backup before clearing browser data or moving phones.

Privacy

Sundae Run does not require an account and does not send your scoop log or photos to a Sundae Run server. Shop search and the optional map contact OpenStreetMap services; those services may receive ordinary request information such as your IP address.

Avoid writing sensitive personal information in notes. Anyone with access to this unlocked device and browser profile may be able to see this journal.

Accessibility statement

We aim for keyboard access, visible focus, labeled controls, readable contrast, reduced-motion support, and compatibility with browser zoom and screen readers. This small independent project has not received a formal third-party accessibility audit.

If something prevents you from using Sundae Run, report the page and control involved to the person who shared this site with you.
